# Home Inventory

The family's map of every shelf, box and thing in storage. Snap photos as you pack, and later anyone can find anything in seconds.

## Start here

- **Family members:** read the [[Family Guide]]. It covers finding things, packing boxes, taking things out and answering requests.
- **Setting it up:** read [[Admin Setup]] for the database keys, accounts and building the shelf sections.
- **Tags and labels:** see [[NFC Tags and Labels]] for where to stick your 30 tags and how to write them.
- **Phones:** [[Android App]] covers the three ways to open it: app, installed web app or website.

## The idea in one picture

```
Storage area (photo)
└─ Section 1 … 15 (one shelving unit; photo; one NFC tag)
   └─ Top shelf · Middle shelf · Bottom shelf · Floor (photo each)
      └─ Box 1, Box 2 … (outside photo, inside photo, owner, lock)
         └─ Things (name, how many, photo, owner, lock)
```

Search goes the other way. Type *"waffle iron"* and the app answers **Section 7 › Middle shelf › Box 41**. Tap **Show me** and that box glows on the shelf wall.
