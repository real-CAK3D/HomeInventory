# NFC Tags and Labels

## The plan for your tags

You have about **30 tags** and **13–15 shelf sections** with **4 shelves each** (including the floor).

**Put one tag on each section**, on the upright at about chest height. Tapping it opens that section with all four shelves and every box on them. That uses 13–15 tags.

One tag per *shelf* would need 52–60 tags, which is more than you have. It's also slower to use: one tap per section shows everything at once anyway.

**Use the spare 15 or so** on the boxes you open most (holiday decorations, important papers, tools), and keep a few for replacements.

| Tag on… | Opens | Link format |
|---|---|---|
| A section | That section, every shelf | `/s/7` |
| A shelf (optional) | That section, scrolled to that shelf | `/s/7/2` |
| A box | That box's list and photos | `/b/41` |

Old tags from the first version (`/tag/001`, `/shelf/001`, `/box/023`) still work.

## Writing tags

### Android (Chrome or the Android app)

1. Make sure **NFC** is on (phone Settings → Connected devices → NFC).
2. In the app: **Me → NFC tags & box labels**.
3. Next to a section, tap **Write**, then **Start**, and hold the back of the phone flat on the tag.
4. When it buzzes and shows a check mark, that tag is done. The list marks it **Written**, so you can see what's left.

Use **Check a tag** to read any tag and see where it points.

### iPhone or computer

Tap the copy button next to a section, then use the free **NFC Tools** app: *Write → Add a record → URL/URI* → paste → *Write* → hold the phone to the tag.

## Printing labels

**Me → NFC tags & box labels → Print labels & signs**

- **Box labels:** a big box number, its name, where it lives, and a QR code. Pick a range (for example boxes 1–40). Tick *include numbers that don't have a box yet* to print labels before you pack.
- **Section signs:** a giant section number, the shelf names and a QR code. Tape one to each unit.

Any phone camera can scan the QR codes, so they work even without NFC.
